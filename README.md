# foodspring-crawler

식자재 도매몰 [식봄](https://www.foodspring.co.kr)에 올라온 상품 전체(상품명·판매가·규격·판매자·카테고리)를 받아 CSV로 저장합니다.
카테고리 화면의 "더보기" 버튼이 보내는 것과 같은 요청을 1초에 한 번씩 보냅니다. 로그인은 필요 없습니다.

## 설치

Python 3.12에서 확인했습니다.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
playwright install chromium
```

`playwright install chromium`은 꼭 실행해야 합니다. 시작할 때 브라우저를 화면 없이 한 번 열어서, 식봄이 로그인하지 않은 방문자에게 주는 쿠키를 받아 오기 때문입니다.

## 빠르게 시험하기

카테고리 1개만 받아 봅니다. 2~3분 걸립니다.

```bash
python scripts/crawl_foodspring_full.py --limit-categories 1
```

끝에 이런 줄이 나오면 잘 된 것입니다.

```
요청 수: 126 (데이터 서버) · 페이지 126
오류 수: 0
상품 수: 이번에 새로 10,000 · 누적(중복 제거) 10,000
완료
```

## 전체 수집

```bash
python scripts/crawl_foodspring_full.py
```

- 카테고리는 약 790개, 상품은 약 23만 개입니다.
- 한 번 실행하면 요청 8,000번에서 멈춥니다(1초에 한 번이라 2시간 넘게 걸립니다). 같은 명령을 다시 실행하면 멈춘 곳부터 이어서 받습니다.
- 중간에 Ctrl+C로 꺼도 됩니다. 페이지마다 저장하므로 받은 데이터는 그대로 남습니다.
- **자정을 넘겨 이어 받을 때는 날짜를 꼭 적어 주세요.** 날짜를 안 적으면 오늘 날짜로 새 폴더를 만들어 처음부터 다시 받습니다.

```bash
python scripts/crawl_foodspring_full.py --date 20261023
```

## 옵션

| 옵션 | 하는 일 |
|---|---|
| `--limit-categories N` | 아직 안 끝난 카테고리 중 앞의 N개만 받습니다(시험용). |
| `--date YYYYMMDD` | 이어 받을 저장 폴더의 날짜입니다. 기본값은 오늘입니다. |
| `--root 경로` | 저장 위치의 기준 폴더입니다. 기본값은 이 저장소 폴더입니다. |
| `--show-files` | 저장 파일 크기, `products.csv` 앞 5줄, 상품번호 중복 수를 보여 줍니다. |
| `--check-sitemap` | 식봄의 공개 상품 주소 목록과 받은 상품번호를 비교해, 얼마나 받았는지 보여 줍니다. |

마지막 줄은 `완료` 또는 `멈춤: <사유>`입니다.

## 결과 파일

`data/raw/foodspring_full/YYYYMMDD/` 폴더에 저장되며, 이 폴더는 git에 올라가지 않습니다.

| 파일 | 내용 |
|---|---|
| `products.csv` | 상품 하나에 한 줄. 열: 상품번호, 상품명, 판매가, 원래가격, 규격, 판매자, 카테고리, URL, 수집시각 (UTF-8 BOM이라 엑셀에서 바로 열립니다) |
| `responses.jsonl.gz` | 요청마다 한 줄씩 서버 응답을 그대로 저장한 원본입니다. 나중에 다른 열이 필요하면 여기서 꺼냅니다. |
| `progress.json` | 이어 받기용 기록입니다(카테고리별 다음 페이지, 끝났는지 여부). 지우면 처음부터 다시 받습니다. |

## 알아 둘 것

- **서버는 목록 하나에서 앞의 10,000개까지만 줍니다.** 상품이 그보다 많은 상위 카테고리는 10,000개에서 끊기고, 나머지는 하위 카테고리를 받을 때 채워집니다. 그래서 위의 시험에서 상품 수가 정확히 10,000으로 나옵니다.
- **배송지역에 따라 보이는 상품이 다릅니다.** 식봄은 접속한 위치(기본값은 서울 중구)를 보고 그 지역에 배송하는 판매자의 상품만 보여 줍니다. 같은 상품의 가격은 지역이 달라도 같았습니다.
- 오류(403·429·5xx·연결 실패)가 10번 연달아 나면 저장하고 멈춥니다. 잠시 뒤 다시 실행하면 이어서 받습니다.
- 요청 간격(1초)과 횟수 상한은 사이트에 부담을 주지 않으려고 둔 것이니 줄이지 말아 주세요.
- 받은 원본 데이터는 팀 안에서 분석할 때만 쓰고, 밖으로 공유하지 않습니다.

## 파일 구성

```
scripts/crawl_foodspring_full.py   실행 진입점
src/wiggly/prices/
  fs_crawl.py      카테고리 전체 수집·저장·이어하기
  fs_api.py        손님 쿠키 받기, 데이터 서버(GraphQL) 요청
  polite.py        요청 간격·횟수 상한·robots.txt
  foodspring.py    검색어 하나로 상품을 찾는 수집기(전체 수집에는 쓰지 않음)
  units.py · rules.py · model.py   규격을 총량·단위가격으로 바꾸는 계산
  *.graphql        데이터 서버에 보내는 질의
```
